# KrishiMitra – PostgreSQL Database Setup Guide

## 1. System Requirements
- PostgreSQL 14+ (Local installation or Managed Cloud instance like AWS RDS / Neon / Supabase).
- Database Name: `krishimitra`
- Default Port: `5432`

---

## 2. macOS Homebrew PostgreSQL Setup

On macOS, PostgreSQL is available via Homebrew:

```bash
# 1. Start the PostgreSQL service
brew services start postgresql@18

# 2. Open PostgreSQL prompt
psql postgres

# 3. Create the database and dedicated user
CREATE DATABASE krishimitra;
CREATE USER postgres WITH ENCRYPTED PASSWORD 'postgres';
GRANT ALL PRIVILEGES ON DATABASE krishimitra TO postgres;
\q
```

---

## 3. Environment Variable Configuration

In `backend/.env` (and root `.env`):
```bash
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/krishimitra
```

> **Note on Zero-Configuration Local Development**:  
> If PostgreSQL service is not active, KrishiMitra gracefully falls back to local SQLite (`sqlite:///./krishimitra.db`) so development and testing can proceed seamlessly without blocking.

---

## 4. Running Migrations with Alembic

Alembic is configured in `backend/alembic/`:

```bash
cd backend
source ../.venv/bin/activate

# Generate an autogenerated migration revision
alembic revision --autogenerate -m "initial_schema"

# Apply migrations to the database
alembic upgrade head

# Rollback one migration if needed
alembic downgrade -1
```

---

## 5. Verifying Connectivity

Test database connectivity using the Phase 1 health endpoint:
```bash
curl http://localhost:8000/api/health/db
```
Expected output:
```json
{
  "status": "healthy",
  "database_connected": true,
  "engine": "postgresql",
  "latency_ms": 1.25,
  "message": "Successfully connected to POSTGRESQL database."
}
```
